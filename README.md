# NotiPuma - API de Difusión

API REST desarrollada para la materia de **Administración de Proyectos**, diseñada para centralizar y organizar avisos institucionales. 

## Tecnologías
* **Backend:** Django y Django REST Framework (DRF).
* **Base de Datos:** PostgreSQL.
* **Control de Versiones:** Git y GitHub.

## Funcionalidades (Endpoints)
* `POST /api/avisos/`: Crear, editar y eliminar avisos (Protegido para administradores).
* `GET /api/avisos/`: Consultar cartelera pública con opción de filtrado por categorías.
